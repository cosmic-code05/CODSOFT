# CODSOFT

Machine Learning Internship Projects completed as part of the **CodSoft Machine Learning Internship**.

I built these projects to gain practical experience in **Machine Learning, Natural Language Processing, text classification, and Deep Learning**. Through the internship, I strengthened my understanding of data preprocessing, feature extraction, model training, evaluation, and neural network based sequence modeling.

This repository contains three projects:

1. **Movie Genre Classification**
2. **Spam SMS Detection**
3. **Handwritten Text Generation using LSTM**

Built using **Python, Scikit-learn, and TensorFlow**.

---

# Projects Overview

## 1. Movie Genre Classification

A text classification project that predicts the genre of a movie based on its plot description.

**Implementation:**

**TF-IDF** was used to convert text into numerical features.

**Logistic Regression** was trained for genre classification.

The trained model predicts the most likely genre based on the provided movie description.

## 2. Spam SMS Detection

A text classification project that identifies whether an SMS message is **Spam** or **Ham** (legitimate).

**Implementation:**

Text data was cleaned and preprocessed.

**TF-IDF** was used for feature extraction.

**Naive Bayes** was implemented for classification.

The trained model was tested using custom SMS messages.

## 3. Handwritten Text Generation

A deep learning project that generates text character by character based on patterns learned from training text.

**Implementation:**

An **LSTM (Long Short-Term Memory)** neural network was implemented.

The model was trained on sample text data.

The trained model generates new sequences based on learned character patterns.
